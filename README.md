# Drarm_v1 (Hand-Tracked Zero-Latency Web Drum)

単眼カメラとWeb標準技術（HTML5 / Canvas / Web Audio API / MediaPipe Hands）のみを用い、机面を手のひらでタップするだけで超低遅延なドラムセッションを実現するキーボードレス・ドラムシステムです。

---

## 主な特徴と変更点（Piarnoからの進化）

1. **指先優先打鍵検出（Fingertip Impulse Tracking）**
   - MediaPipe Handsの各指先（TIP: 4, 8, 12, 16, 20）をダイレクトにトラッキング。
   - 机面に最も近い主動打鍵指先（Lead Fingertip）のY軸下向き速度が急制動・反転する「Y軸方向に減少する動きの加速度スパイク」を直接捉え、極小レイテンシでドラムを発音。
   - 全指先に白丸マーカーを配置し、打鍵した瞬間に主動指先マーカーが強力に発光・フラッシュする直感的なビジュアルフィードバックを提供。
   - 両手（左右の手）の並行追従に対応し、リアルタイムなドラムロールや両手コンビネーション演奏が可能です。

2. **画面左右による直感的な音色分岐**
   - **画面中央より左（CYMBAL エリア）**:
     - 上部 / 強打: **Crash Cymbal（クラッシュシンバル）** - 広がりと長時間の金属残響
     - 中央〜下部: **Hi-Hat（ハイハット）** - 切れ味鋭いメタリックノイズ（オープン / クローズド）
   - **画面中央より右（DRUM エリア）**:
     - 下部（机面付近）: **Bass Drum / Kick（バスドラム）** - 瞬時ピッチスイープの重低音
     - 中央部: **Snare Drum（スネア）** - スナッピー＋シェルトーン
     - 上部: **Tom（タム）** - ウォームなピッチディケイ

3. **完全フリーセッション ＆ ガイド撤廃**
   - 楽曲選択や落下ノーツなどの制約を一切排し、叩いた瞬間に発音するストレスフリーな即興演奏環境。

4. **脱AI・完全ボーダーレス・アイコンファーストUI**
   - 枠線（ボーダー）を一切使わず、面のトーン差・タイポグラフィ・余白のみで表現。
   - テキストボタンや装飾を排除し、直感的なSVGアイコンと白黒ミニマルなビジュアルフィードバック（波紋リップル・面フラッシュ）を採用。

5. **Piarno打鍵データセット駆動の閾値キャリブレーション**
   - `public/dataset/` 内の打鍵時系列データ（CSV）を起動時に解析し、生体力学的な変位・速度閾値を自動適用。

6. **Piarno 1D パイプラインによる最適化とカメラフリーズ根絶**
   - **タイムスタンプ厳密単調増加**: MediaPipe Tasks Vision C++エンジンの内部アサートエラーを防ぐため、フレーム毎のタイムスタンプが必ず `+1.0ms` 以上進むように保証し、カメラフリーズを完全解消。
   - **カメラ物理フレーム同期**: `requestVideoFrameCallback` により物理フレーム到着と1:1同期推論を実施。無駄な重複推論を全廃。
   - **解像度1:1同期**: Canvasのピクセル解像度をビデオ解像度に直結させ、CSSの `object-fit: cover` に任せることで、高DPI端末でもレンダリング負荷を最小化。
   - **手首飛び移り遮断**: 手首の画面対角25%を超える瞬間ジャンプを検知してリセットし、左右の手の混線や誤打鍵を防止。

7. **動画編集型アノテーションスタジオ（プレビュー確認＆手動Hitマーカー設置）**
   - 撮影済みの動画（WebM / MP4）を読み込み、動画編集ソフトのように大画面プレビューで骨格トラッキング（手の関節・指先十字ターゲット）を目視確認。
   - **ズレ根絶と左右反転（FLIP）同期**: 動画のネイティブ解像度とCanvasを1:1同期させ、自撮りインカメラ動画でもボタン一つで映像と骨格を同時に鏡像反転。
   - **コマ送り・スロー再生**: スペースキーでの再生/停止、矢印キー（`←` / `→`）での1コマ・5コマ送り、0.25x / 0.5x スロー再生に対応。
   - **手動Hitマーカー（打鍵設置）**: 机を叩いた瞬間を見極めて `H` キー（または MARK HIT ボタン）を押すことで、タイムライン上に打鍵ピンを記録（ドラム音試聴＋白熱フラッシュ発光）。
   - **高品質グラウンドトゥルースCSV出力**: ユーザーが目視で打った確実なHitラベル（1/0）と、MediaPipeの骨格座標・相対変位 `ry`・速度 `dy` を結合したCSVをワンクリックでエクスポート。

## ディレクトリ構成

```text
Drarm_v1/
├── index.html              # メインUI（完全ボーダーレス・アイコンファースト）
├── style.css               # 白黒ミニマル・トーン差デザインスタイル
├── main.js                 # MediaPipe推論・加速度算出・プロシージャル合成音源
├── package.json            # プロジェクト定義
├── vite.config.js          # Vite設定
├── Recipe_of_Piarno.md     # Piarno数理・幾何モデル技術解説書（参照用）
├── public/
│   ├── dataset/            # Piarno打鍵データセット（CSV & manifest）
│   └── models/             # MediaPipe HandLandmarker モデルアセット
```

## 起動方法

### ローカルサーバー起動

```bash
# 方法1: npm スクリプト
npm run serve

# 方法2: Python直接起動
python -m http.server 5173
```

ブラウザで `http://localhost:5173` にアクセスし、カメラの利用を許可してください。
（画面左上のスピーカーアイコン、または画面タップでオーディオが有効化されます）
